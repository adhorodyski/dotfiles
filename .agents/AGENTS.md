# AGENTS.md

## Rules

1. **Never break user space.** Working product behavior is sacred: UI flows, API contracts, anything users touch. If a change risks breaking it, stop and surface the trade-off.
2. **Link GitHub issues and PRs.** Write each one as a markdown link whose label names the repo: `[widgets#123](https://github.com/acme/widgets/issues/123)`, `/pull/` for PRs. A bare `#123` is unclickable and drops the repo.
