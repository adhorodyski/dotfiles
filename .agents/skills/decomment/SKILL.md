name: decomment
description: >
  Strip code comments. Keep only a comment that explains a hack over external
  code. Use when user says "decomment", "strip comments", "remove comments",
  or invokes /decomment.
---

Delete every code comment except one that explains a hack over external code, such as a workaround for a library bug or an API quirk, and let the rest of the code explain itself.
